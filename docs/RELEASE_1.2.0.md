# 1.2.0 更新

- 管理員可修改會員編號與名稱，例如 49 → 049；會員內部 ID、QR 與帳本關聯保留。
- 管理員可補登過去交易，分別保留交易日期與實際登錄時間。補登影響目前餘額，歷史餘額不重寫。
- 發點、扣點、餘額調整、固定額度與員工額度上限支援 0.5 點。
- 管理員可用 .xlsx 整批新增會員，第一列為「會員編號」「會員名稱」。最多 2000 列／5 MB，錯誤整批回滾，既有會員不覆寫。文字編號與 000 格式數字可保留前導零。
- 交易畫面以完整會員編號查詢，查詢與 CSV 使用一致條件。
- 正式部署改用 SQL Server Express，透過資料庫交易鎖保護多裝置寫入，保留冪等性與不可變帳本。

**升級前必讀 [SQL Express 建置與移轉](SQL_EXPRESS.md)。舊版只更新 EXE 的方式不適用此次資料庫切換。** SQL Express、ODBC 與來源資料移轉須依步驟完成。既有 QR 密鑰必須保留。

原始碼已提供 SQL Express 建置、移轉及整合測試；實際部署前須完成 SQL Express 整合、備份還原及工作站驗收。
